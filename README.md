# Swiss Horizon

Travel website for Switzerland: small-group, rail-first journeys. Built with **Astro 5** and **Tailwind CSS 4**, deployed as a static site.

## Pages

| Route | Page |
|---|---|
| `/` | Home: hero, journeys, a day on the trail, departures, FAQ |
| `/destinations/` | Ten Swiss destinations, filterable |
| `/things-to-do/` | Peaks, scenic trains, lakes, food, festivals, winter |
| `/travel-tips/` | Transport, money, entry, seasons, etiquette, budget |
| `/contact/` | Booking request form and contact details |

## Develop

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
```

## Media

All photos come from the Unsplash API and are served from Unsplash's CDN at responsive sizes. Every photographer is credited in the footer.

- `scripts/queries.json`: place-specific search terms.
- `scripts/unsplash-search.mjs`: runs the searches and caches results in `.cache/` (gitignored). Needs `UNSPLASH_ACCESS_KEY`.
- `scripts/picks.json`: which result fills which slot on the site. Each pick was checked by eye, and by its Unsplash location or description where available, to make sure it was taken in Switzerland.
- `scripts/build-media.mjs`: writes `src/data/media.json`, which the site reads.

API keys are read from environment variables only and never committed.

## Content

- `src/data/site.ts`: home page content, journeys, departures, FAQ.
- `src/data/destinations.ts`, `src/data/things.ts`: content for the inner pages.
- Facts that must be checked before launch are listed in `FACTS-TO-VERIFY.md`.

## SEO

Each page has its own title, description, canonical URL, Open Graph and Twitter image, and TravelAgency JSON-LD. The sitemap is generated by `@astrojs/sitemap`, and `robots.txt` is in `public/`. Set `SITE_URL` for the production domain.
